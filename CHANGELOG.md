# 📝 Changelog - Lumora Social

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere al [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### 🚀 Agregado
- Sistema de eventos completo con calendario interactivo
- Marketplace con catálogo de productos y carrito
- Sistema de facetas (multiperfil) avanzado
- Feed cruzado inteligente con algoritmos personalizables
- Chat en tiempo real con sidebar de miembros
- Sistema de notificaciones en tiempo real
- Panel de configuración personalizable
- Editor de texto rico (WYSIWYG) con TipTap
- Sistema de filtros avanzados para todos los módulos
- Banner de eventos en vivo con indicadores animados

### 🔧 Mejorado
- Optimización de rendimiento con React 19
- Mejoras en la experiencia móvil
- Sistema de temas más robusto
- Navegación más intuitiva
- Animaciones más fluidas con Framer Motion

### 🐛 Corregido
- Errores de hidratación en SSR
- Problemas de compatibilidad con React 19
- Errores de TypeScript en componentes
- Problemas de cache en Next.js

  - TypeScript configurado
  - Tailwind CSS 4
  - Shadcn/UI components
  - Framer Motion para animaciones

- **Sistema de autenticación**
  - Login/Logout funcional
  - Gestión de sesiones
  - Protección de rutas

- **Layout principal**
  - Sidebar navegacional
  - Header con búsqueda
  - Sistema de temas (dark/light)

- **Páginas básicas**
  - Landing page
  - Feed principal
  - Perfil de usuario
  - Explorar espacios

- **Componentes UI**
  - Sistema de componentes base
  - Modales y diálogos
